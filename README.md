## Repository Focus & Statistical Framework

This repository serves as a comprehensive toolkit for inferential statistics and advanced data analytics. It contains robust data-driven frameworks designed to extract business intelligence using precise hypothesis testing methodologies across numerical, categorical, and proportional datasets.

## Core Statistical Capabilities Matrix

The scripts and projects housed in this repository span the following inferential domains:

*   **Continuous / Numerical Testing (Means)**
    *   **Z-Tests:** Large-sample population mean evaluations ($n \ge 30$).
    *   **One-Sample T-Test:** Evaluating a single sample mean against a historical target when population parameters are unknown.
    *   **Two-Sample Independent T-Test:** Comparing the average metrics between two distinct, unrelated groups (e.g., Male vs. Female spending).
*   **Variance & Group Comparisons**
    *   **One-Way ANOVA:** Testing for statistically significant differences across three or more independent groups based on a single factor.
    *   **Multi-Way ANOVA (Factorial):** Evaluating the simultaneous interaction and main effects of multiple categorical factors on a continuous variable.
*   **Categorical & Distributional Analysis**
    *   **Chi-Square Test of Association:** Identifying dependencies and correlation metrics between distinct categorical attributes.
    *   **Chi-Square Goodness-of-Fit:** Validating whether an observed categorical distribution matches an expected theoretical baseline.
*   **Proportional Metrics**
    *   **One-Sample Proportion Test:** Assessing binary success rates against an established baseline percentage.
    *   **Two-Sample Proportion Test:** Evaluating conversion, churn, or performance metrics between two unique treatment groups (e.g., A/B testing).
